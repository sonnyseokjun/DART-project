개인정보처리방침

"공시 쉽게 보기"(이하 "서비스")는 이용자의 개인정보를 필요한 만큼만 받고, 받은 정보는 아래 목적에만 씁니다.

1. 받는 정보

항목받는 방법쓰는 곳
카카오 회원번호 카카오 로그인 시 자동 제공 회원 식별, 로그인 유지
닉네임 카카오 로그인 시 동의 후 제공 화면에 이름 표시
접속 기록(IP 주소, 접속 시각, 요청 주소) 서비스 이용 시 자동 생성 장애 대응, 부정 이용 방지

이메일, 전화번호, 프로필 사진, 비밀번호는 받지 않습니다. 로그인 상태 유지를 위해 브라우저 쿠키를 사용합니다.

2. 보관 기간과 삭제

  • 회원 정보는 탈퇴하는 즉시 삭제합니다. 카카오 앱에서 이 서비스와의 연결을 끊은 경우에도 같습니다.
  • 서비스 복구를 위한 백업본에는 삭제 전 정보가 남을 수 있으며, 백업본은 최대 30일 뒤 자동으로 삭제됩니다.
  • 접속 기록은 일정 용량이 차면 오래된 것부터 자동으로 삭제됩니다.

3. 제3자 제공

이용자의 개인정보를 다른 곳에 제공하지 않습니다.

4. 처리 위탁

맡기는 곳맡기는 일
Amazon Web Services (서울 리전)서버 운영, 데이터 백업 보관
