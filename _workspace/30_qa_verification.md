## 3. 남은 결함을 숨기지 않고 테스트로 고정했다

qa 는 못 고친 것을 **실패하는 테스트가 아니라 "현재 동작"을 기록하는 테스트**로 남겼다.
고쳤다고 착각하지 않기 위해서다.

| 테스트 | 고정한 사실 |
|---|---|
| `test_thousand_fold_errors_pass_the_multiplier_menu` | **1000배 오류는 지금도 검증기를 통과한다** (`_SCALE_MULTIPLIERS` 에 10³ 이 있어서) |
| `test_item_number_can_still_justify_a_ten_fold_error` | 항목 번호가 10배 오류의 근거로 오인될 수 있다 |
| `test_original_share_wording_is_misread_as_won` | 주식 수 표현이 금액으로 읽힐 수 있다 |
| `test_a_strictly_worse_correction_is_still_accepted` | 재생성 결과가 더 나빠져도 채택된다 |
| `test_exact_amounts_are_annotated_twice_when_applied_twice` | 주석 달기는 정확 금액에 한해 비멱등이다 |

10배 오류가 잡히는 이유는 10이 `_SCALE_MULTIPLIERS` 에 **없기** 때문이지 검증기가 배수 오류를
일반적으로 잡아서가 아니다. 이 구분이 문서에 남아야 다음 사람이 검증기를 과신하지 않는다.

- **유형 게이트 18건** — 자본구조 변동처럼 "틀렸을 때 되돌릴 수 없는" 공시. 이건 줄이는 게
