## ⚠️ 발견된 필드 불일치 (버그) → ✅ 해결됨

- `poll_dart.py:53`이 `item.get('pblntf_ty', '')`로 **`disclosure_type`을 채우려 했으나, list.json 항목에 `pblntf_ty` 필드가 없음.**
- 결과: 초기 적재 755건 전부 `disclosure_type=''` (빈값).
- 원인: DART에서 `pblntf_ty`(공시유형: A정기/B주요사항/C발행/D지분/E기타/F외부감사/G펀드/H자산유동화/I거래소/J공정위)는 **요청 필터 파라미터**일 뿐, 응답 항목에는 포함되지 않는다.

### 해결 방식: 유형별 분할 조회

- `pblntf_ty` A~J로 나눠 `list.json`을 조회하고, 각 결과에 그 유형명을 태깅한다.
- **호출 오버헤드가 작다**: 유형은 전체 공시를 분할하므로(합계 = 전체) 페이지 수 합이 단일 조회와 거의 같다. 실측: 단일 40페이지 → 유형별 합계 44페이지(+10%).
- **호출 수는 기업 수와 무관**(고정 유형 10종) → PLAN.md 12.2 원칙 유지.
- **추적 기업 완전 포착 확인**: 유형별 수집한 추적기업 공시 = 무필터 수집 755건과 정확히 일치(놓침 0). 시장 전체의 3.7% 사각지대(무필터 3,989 vs 유형합 3,843)는 추적 기업엔 해당 없음.
- 구현: `dart.py`에 `PBLNTF_TYPES` 상수 + `list_disclosures/iter_disclosures`에 `pblntf_ty` 파라미터, `poll_dart`가 유형 순회하며 태깅.
- 정밀 유형 세분화·중요도는 2단계 LLM이 원문까지 보고 별도 판정(본 유형은 대분류로 admin 필터·비용 티어링용).
